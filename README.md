        <li>Forecasted ride demand using <b>SARIMA</b> and <b>XGBoost</b></li>
        <li>Estimated potential recovery of <b>~₹71K revenue</b> through targeted interventions</li>
        <li>Delivered a data analysis notebook, forecasting models, and Power BI dashboard</li>
